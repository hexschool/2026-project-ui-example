怎麼使用這份設計稿

每個主題有一份共用的需求（頁面、文案、wireframe），再用不同的視覺風格做出完整的設計稿。每套風格都有三個入口：

網站樣式網站樣式
設計稿本身。從首頁開始，用頁首導覽和頁面上的按鈕走完整個流程。播放、倒數、付款中這類動態功能以靜態畫面呈現，其他狀態（空狀態、錯誤、售完…）放在頁面底部虛線框的「設計稿狀態示意」。
GuidelineGuideline
這套風格的設計規範：色彩、字級階層、間距、圓角陰影、元件狀態、RWD 斷點與 Do／Don't 對照，以及這套風格的招牌元素怎麼用。
原始碼原始碼
GitHub 上這套風格的專案資料夾。每套都是獨立專案：Bootstrap 5（用 Sass 變數客製）＋ HTML＋CSS＋少量 JS，沒有打包工具。

建議的閱讀順序

  1. 先看主題說明與 wireframe，掌握有哪些頁面、使用者怎麼走。
  2. 把同一個主題的三套風格對照著看：一樣的內容，用不同的色彩、字體與版型呈現。
  3. 打開 Guideline，看 design token 與元件狀態是怎麼定義的。
  4. 讀原始碼：從 scss/_variables.scss 開始，再看 templates/page.html 與各頁 HTML。

在自己的電腦上

clone 下來後直接用瀏覽器打開本頁（根目錄的 index.html）即可。要修改某套風格的樣式：

cd 02-影音課程平台主題/01-dark-theater-style
npm install      # 安裝 bootstrap、sass
npm run watch    # 監看 scss/，存檔就重新編譯 css/style.css

所有頁面都在 390、1440、1920 三種寬度檢查過。

名詞清單

討論設計稿時統一用以下說法。

設計稿樣式站
就是本頁：統整所有主題與風格的入口，可以從這裡另開新分頁到每一套設計稿。
主題
一種網站類型，例如電商、影音課程平台。每個主題有自己的品牌、文案、頁面清單與 wireframe，編號 01～05。
風格
同一個主題用一種視覺語彙做出的一整套設計稿，名稱與編號沿用 Notion 風格表，例如「02 影音課程平台 × 01 極致暗黑劇院」。
網站樣式
可以直接瀏覽的設計稿頁面，從每套風格的 index.html（首頁）開始。
設計 Guideline
每套風格的設計規範頁（guideline.html）：色彩、字級階層、間距、圓角陰影、元件狀態、RWD 斷點與 Do／Don't 對照。
原始碼
每套風格的專案資料夾：HTML、SCSS、少量 JS、圖片與生圖腳本。
Wireframe
主題共用的版型骨架，只決定有哪些頁面、區塊的順序與欄數，不決定視覺。每個主題的 _wireframe/ 資料夾裡有本地副本與逐頁規格（WIREFRAME_SPEC.md）。
Design token
一套風格的色彩、字體、間距、圓角、陰影等設計變數，集中寫在 scss/_variables.scss，Guideline 的數值與它一致。
招牌元素
每套風格最有代表性的一兩個設計，對應 Notion 風格表的「UI 視覺特點」，例如結帳頁的金屬卡片、票券的打孔票根。
設計稿狀態示意
頁面底部以虛線框標示的區塊，示範正常畫面以外的狀態：空狀態、錯誤、售完、未登入等。

使用須知

  • 品牌、商品、課程、活動、專案、文章、人物與所有數據都是虛構的示意資料。
  • 圖片由 AI（Codex CLI 的 image_generation）生成，僅供課程示意；每套風格的生圖腳本與提示詞在 scripts/generate-images.mjs。
  • 文案取自 Notion 需求文件並逐字使用；Notion 沒寫、畫面需要補充的文字，記錄在各主題的 CONTENT.md 與各風格的 README。
  • 字體從 Google Fonts 載入，離線時會改用系統字體。
  • 授權與轉載規則以六角學院的課程公告為準。
