UI 風格範例站

這個網站是專題前端畫面的參考。五種主題類型各有 6 套視覺風格，每套都有完整的範例頁面、設計規範（Guideline）與原始碼。

總目錄

點一套風格就會進入預覽。設計稿放在外框裡，外框上方可以換頁面、切換成平板或手機寬度，也可以換到同主題的其他風格。

怎麼使用範例站

使用方式

全組從你們主題類型的風格中選一套，照它的 Guideline 設計頁面。範例站是參考，要沿用多少原始碼由全組決定，唯一的要求是專案要有自己的樣式設定（_variables.scss），畫面不是 Bootstrap 預設外觀。

什麼時候用
里程碑 3「開發環境與資料層建置」的「版型套用」：全組會在這裡選一套風格、建立樣式設定，里程碑 4 再參考範例頁完成頁面套版。純後端組則是在里程碑 4 拿來做展示用畫面。
題材由你們決定
每個主題類型的品牌與內容只是範例。例如電商交易平台的範例題材是家居選物「NestCraft」，你們可以做寵物用品、咖啡豆或二手書，只要主題類型是電商交易平台，就能用這裡的電商交易平台風格。

使用步驟

  1. 第一步

    確認主題類型

    找到你們選定的主題類型（電商交易平台、影音課程平台、活動票務系統、群眾募資網站、知識內容訂閱服務），跳到下方對應的區塊。整合版在里程碑 2 選定主題類型，單人組在里程碑 1；學習組固定是電商交易平台。

  2. 第二步

    比較風格，全組選一套

    每套風格點「網站樣式」進入預覽，從首頁開始，用設計稿裡的導覽和按鈕走完整個流程，再按外框上方的「手機」看一次手機寬度（視窗太窄時沒有這顆按鈕，拉寬就會出現）。按「上一套」「下一套」會停在同一頁，方便比較。想一想這套風格的招牌元素適不適合你們的題材。想用其他主題類型的風格，請先跟教練討論工時。選定後，把「主題類型 × 風格」與範例站連結寫進 README。

  3. 第三步

    讀 Guideline 與原始碼

    打開「Guideline」，看色彩、字級、間距、圓角與 Do／Don't 對照。打開「原始碼」，先讀這套風格的 README.md（「共用類別」與「Design token 摘要」兩段），再看 scss/_variables.scss。各範例頁（首頁與 Guideline 除外）拉到最底，看虛線框的「設計稿狀態示意」。

  4. 第四步

    套用到你們的專案

    版型對照表、建立 _variables.scss、抽共用元件、組出頁面，請照里程碑 3「版型套用」的步驟 3～6 進行。分兩個里程碑完成：

    • 里程碑 3：步驟 3～4（版型對照表、建立樣式設定），加上步驟 5 的 Header、Footer、Admin Sidebar。
    • 里程碑 4：步驟 5 其餘的共用元件與狀態元件，以及步驟 6 的頁面套版。

第四步是純前端組、前後端組與單人組的做法。純後端組不用套版，里程碑 4 的展示用畫面可以直接拿同主題的一套風格，把寫死的假資料改成用 fetch 打你們的 API（見里程碑 3「之後要準備：展示用畫面」）。學習組照學習組里程碑 3 的第 6 步建立樣式設定，里程碑 4 再參考範例頁套樣式。

每套風格的三個入口

網站樣式網站樣式
這套風格的完整範例頁面，會在預覽的外框裡打開。播放、倒數、付款中這類動態功能以靜態畫面呈現；空狀態、錯誤、售完、未登入等狀態，放在頁面底部虛線框的「設計稿狀態示意」。拿來看畫面與流程，決定選哪一套。
GuidelineGuideline
色彩、字級階層、間距、圓角陰影、元件狀態、RWD 斷點、Do／Don't，以及這套風格的招牌元素。這是規則書：自己延伸其他頁面時照著做，整站才會一致。
原始碼原始碼
GitHub 上這套風格的專案資料夾：Bootstrap 5（Sass 變數客製）＋ HTML＋CSS＋少量 JS，沒有打包工具。需要時可以沿用樣式（scss/），或參考頁面的 HTML 結構。

下載原始碼

在 GitHub 專案頁按「Code → Download ZIP」，或用 git clone 下載整個專案，用瀏覽器打開根目錄的 index.html 就能離線瀏覽。

要沿用樣式時，整套沿用就複製該風格的 scss/ 資料夾，只沿用設定就複製 scss/_variables.scss。請引入 Sass 原始檔，不要直接引入編譯好的 css/style.css。作法見里程碑 3「版型套用」步驟 4。

範例頁的 <head> 會載入 frame-guard.js，讓直接打開的頁面也有外框。要複製整頁 HTML 到自己的專案時，把那兩行（註解與 <script>）刪掉。要整頁截圖或列印（例如把 Guideline 存成 PDF）時，把整個風格資料夾複製到別的地方再打開，就不會有外框。

所有頁面都在 390、1440、1920 三種寬度檢查過。

（進階）想直接在範例站上試改某套風格的樣式：

cd 02-影音課程平台主題/01-dark-theater-style
npm install      # 安裝 bootstrap、sass
npm run watch    # 監看 scss/，存檔就重新編譯 css/style.css

使用須知

  • 品牌、商品、課程、活動、專案、文章、人物與所有數據都是虛構的示意資料。登入、註冊、結帳等表單只是畫面，請勿輸入真實資料。
  • 後台目前沒有範例頁，請照 Guideline 自己延伸，沿用與前台同一套 token 與間距規則。可以參考的頁面：知識內容訂閱服務的個人頁面有管理員視角，群眾募資網站的個人頁面有提案者的提案管理。
  • 範例站的圖片都由 AI（Codex CLI 的 image_generation）生成，僅供課程示意。你們的專題可以到 Unsplash（另開新分頁） 或其他版權開放的圖片網站找素材；想用 AI 生成的話，可以參考每套風格原始碼裡的生圖腳本與提示詞 scripts/generate-images.mjs。
  • 字體從 Google Fonts 載入，離線時會改用系統字體。
  • 可自由修改；不得原封不動對外宣稱為個人原創設計；README 與發表簡報請標註使用的風格，例如「六角 2026 專題班 UI 風格範例站：01 電商交易平台 × 02 日系無印風」。
  • 授權與轉載規則以六角學院的課程公告為準。
