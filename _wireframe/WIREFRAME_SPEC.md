# NestCraft 原創生活家居選物：Wireframe 版型規格

> 所有設計風格（每套一個 Vite + Vue 3 + Bootstrap 5 專案）共用這份版型規格。
> 本文件只規定**資訊架構與版型**：頁面清單、區塊順序、欄數配置、元件、互動狀態、RWD。
> **視覺風格**（配色、字體、圓角、陰影、圖片、icon 風格、裝飾）與**尺寸 token**（容器內距、元件高度、字級）由各風格自行決定。
> **商品、分類、首頁文案的唯一來源是 Notion「設計稿範例產出文件」**，逐字使用，各專案放在 `src/data/products.js`。wireframe 裡的品牌「居所家具」、商品 A～F、金額、庫存、訂單都只是版型佔位，不要照抄（見 §2.6、§2.7）。
> **本次範圍**：設計 Guideline＋前台 9 頁為必做；後台 A1～A5 為選做，之後再做。

- 來源：<https://cartflow-plum.vercel.app/>（v0 產生、Next.js SSR 的低保真線框圖，原站標題「居所家具選物 — 電商流程線框圖」；「居所家具」是佔位品牌，品牌一律用 NestCraft）
- 鏡像日期：2026-09-23（原站 HTML 與同日稍早抓的版本完全相同）
- 對照檔：`pages/<檔名>.html`（可直接用瀏覽器開啟的靜態鏡像）、`screenshots/<檔名>.png`（1440 寬原站全頁截圖）
- 參考實作：`../02-muji-style/`（日系無印風）。文中寫「02 的做法」的地方是參考，不是規定。
- 閱讀順序建議：先看〈0. 實作原則〉→〈1. 頁面清單〉→〈2. 全域規格〉→ 要做哪頁就看〈3〉的該頁小節；最後用〈5. 檢核清單〉自我檢查
- 文中的 px 數值都是 **wireframe 的實測值**，用來理解比例與層級；實際尺寸由各風格的 token 決定

## 0. 實作原則：哪些要照做、哪些可以發揮

| 必須遵守（跨風格一致） | 可自由發揮（風格差異） |
|---|---|
| 設計 Guideline＋前台 9 個頁面與路由（見 §1）；後台 A1～A5 為選做 | 色彩、字體、字級比例 |
| 每頁的**區塊順序**與**桌機欄數配置** | 圓角、陰影、邊框、分隔線樣式 |
| 每個區塊包含的元件與表單欄位 | 圖片內容、插畫、icon 套件（原稿用 Lucide） |
| **首頁與商品文案逐字採用 Notion，不可改寫**；wireframe 上的文字只用來對照位置。Notion 沒寫到的介面文字（表單標籤、按鈕、提示）沿用 wireframe 的意思，可以調整語氣 | 區塊內的留白比例（但要維持閱讀層級） |
| 商品的品名、介紹、尺寸、分類、價格照 Notion（§2.6） | 尺寸 token：容器內距、元件高度、字級（本文的 px 只是 wireframe 實測） |
| 互動狀態：選中、停用、售完、低庫存、狀態徽章 | hover、轉場動畫等微互動；按鈕或連結旁是否加 icon |
| RWD 的收合順序（見各頁〈RWD〉） | 在規格外額外加入的裝飾性元素 |

### 0.1 線框圖符號怎麼讀

wireframe 用了一套「標記語言」來表示區塊與資料，**這些標記不是文案，也不是字體或樣式規格**，不要照搬到正式畫面上。

| 線框圖裡看到的 | 代表 | 實作時 |
|---|---|---|
| 灰底＋對角交叉線的框（`.wire-crossbox`），中間有小標籤如「IMAGE」「主圖」「ROOM 01 / ROOM HOTSPOTS」 | 圖片佔位 | 換成真實圖片或插畫，**比例照規格**（1:1、固定高度等） |
| 數條灰色細長橫條（寬 92% / 86% / 80% / 55%） | 長段落佔位 | 換成真實段落文字 |
| 10px 等寬大寫小字，例如「VALUE PROPOSITION / 4 PRINCIPLES」「金額摘要」 | **區塊標籤**（SectionLabel） | 中文標籤（「金額摘要」「收件資訊」）代表這裡需要一個小標題，用風格自己的標題樣式（h2／h3）；英文全大寫標籤只是註記，**不顯示** |
| 文字後面的 →、← 與 ›（例如「探索空間靈感 →」「← 繼續購物」「查看訂單詳情 ›」） | wireframe 的 Lucide icon，**不是文案** | 文案不含箭頭。是否加 icon 由風格決定，避免每顆按鈕都加 → |
| 「ROOM 01／02／03」這類編號眉標 | 佔位編號 | 不要照搬。Notion 用「情境 A／B／C」區分，畫面上直接用空間名稱（【5 坪微型公寓】）即可 |
| 用「·」串起來的資訊列（「商品編號 p-1001 · 餐桌椅」「訂單 ORD-20260801 · 2026-08-01」） | 資訊密度的示意 | 拆成有標籤的資訊（分行、`<dl>` 或各自的小標），不要用中點串成一列 |
| 等寬字（Geist Mono）的價格、分類、標籤 | 標示「這裡是資料」 | 不是字體規格。數字建議 `font-variant-numeric: tabular-nums`，字體照風格 |
| 標為〔標註〕的文字，例如「HERO BANNER / BRAND STATEMENT」「[ IMAGE PLACEHOLDER ]」「註：付款失敗時…」 | 給設計師看的說明 | **不要**顯示在正式畫面上，改成實作對應的功能或狀態 |
| 品牌「居所家具 / logo」、商品 A～F、金額、庫存、訂單 | 佔位資料 | 品牌用 NestCraft；商品與文案用 Notion（§2.6） |
| 灰底長方塊裡放著灰字（例如「mail@example.com」） | 表單輸入框，灰字為 placeholder 或預填值 | 用真正的 `<input>`／`<select>`／`<textarea>` 實作 |
| 深色實心按鈕 | 主要行動（Primary） | Bootstrap `.btn-primary` 或同等樣式 |
| 白底細框按鈕 | 次要行動（Secondary） | `.btn-outline-*` 或同等樣式 |
| 淺灰底、灰字的按鈕 | 停用（disabled） | 加 `disabled` 屬性，游標 `not-allowed` |

## 1. 頁面清單

版型家族：**F** = 前台標準（共用頁首＋頁尾）、**A** = 後台側欄框架、**AL** = 後台登入（沒有頁首，有頁尾）。
頁面名稱以 Notion／專案為準；wireframe 的頁名只用來對照鏡像檔。

| # | 頁面（Notion／專案頁名） | wireframe 頁名 | 路由（= 建議 Vue Router 路徑） | 鏡像檔 `pages/` | 家族 | 容器寬度（wireframe） | 範圍 |
|---|---|---|---|---|---|---|---|
| 00 | 設計 Guideline | （wireframe 沒有此頁） | `/guideline` | — | F | 各風格自訂 | **必做** |
| 01 | 首頁 | 首頁 | `/` | `home.html` | F | 1152px（各區塊自訂） | **必做** |
| 02 | 商品列表（頁內標題可用「商品一覽」） | 商品瀏覽 | `/products` | `products.html` | F | 1152px | **必做** |
| 03 | 商品詳情 | 商品內頁 | `/product/:id`（p-1001～p-1010） | `product-p-1001.html`～`product-p-1006.html` | F | 1152px | **必做** |
| 04 | 購物車 | 購物車 | `/cart` | `cart.html` | F | 1024px | **必做** |
| 05 | 登入 | 會員登入 | `/login` | `login.html` | F | 448px | **必做** |
| 06 | 註冊 | 會員註冊 | `/register` | `register.html` | F | 448px | **必做** |
| 07 | 結帳 | 結帳付款 | `/checkout` | `checkout.html` | F | 1024px | **必做** |
| 08 | 付款結果 | 付款結果 | `/order-result` | `order-result.html` | F | 672px | **必做** |
| 09 | 我的訂單 | 我的訂單 | `/orders` | `orders.html` | F | 896px | **必做** |
| A1 | 後台登入 | 後台登入 | `/admin/login` | `admin-login.html` | AL | 448px | 選做／之後再做 |
| A2 | 商品管理列表 | 商品管理列表 | `/admin` | `admin.html` | A | 滿版（扣掉側欄） | 選做／之後再做 |
| A3 | 新增商品 | 新增商品 | `/admin/products/new` | `admin-products-new.html` | A | 896px | 選做／之後再做 |
| A4 | 編輯商品 | 編輯商品 | `/admin/products/:id/edit` | `admin-products-p-1001-edit.html` | A | 896px | 選做／之後再做 |
| A5 | 訂單管理 | 訂單管理 | `/admin/orders` | `admin-orders.html` | A | 滿版（扣掉側欄） | 選做／之後再做 |

**00 設計 Guideline**：Notion 規定每套風格的第一頁，wireframe 沒有，版型由各風格自訂，但必須包含這 6 項：

1. 色彩：品牌色、中性色、語意色（成功／警示／錯誤）與用途
2. 字級階層：標題、內文、輔助文字的字級與行高
3. 間距：間距尺度，以及區塊、元件之間怎麼用
4. 圓角陰影：圓角與陰影（或不用陰影時的分層方式）
5. 元件狀態規範：按鈕、表單欄位、選項、分頁籤等的預設／hover／focus／停用／錯誤狀態
6. RWD 斷點與 Do／Don't 對照：Bootstrap 斷點的版型變化，以及正確與錯誤用法的並排對照

02 的做法：把第 6 項拆成「RWD 斷點」「Do／Don't 對照」兩節，另加一節概覽，並用 `/guideline` 路由。

- 使用者流程（wireframe 頁尾索引的順序）：首頁 → 商品列表 → 商品詳情 → 購物車 → 登入 → 註冊 → 結帳 → 付款結果 → 我的訂單
- 管理者流程（選做）：後台登入 → 商品管理列表 → 新增商品／編輯商品 → 訂單管理
- 使用 hash 模式（`/#/products`）也可以，路徑名稱請保持一致。

## 2. 全域規格

### 2.1 斷點與容器

原稿是 Tailwind，斷點與 Bootstrap 5 略有不同。**以 Bootstrap 斷點為準**，對照如下：

| 原稿（Tailwind） | 寬度 | 對應 Bootstrap | 寬度 |
|---|---|---|---|
| `sm:` | ≥ 640px | `sm` | ≥ 576px |
| `md:` | ≥ 768px | `md` | ≥ 768px |
| `lg:` | ≥ 1024px | `lg` | ≥ 992px |
| — | — | `xl` | ≥ 1200px |

- 檢核寬度：**1440／1200／992／768／390**（含 Bootstrap md／lg／xl 邊界與手機）。

| 原稿容器 | 最大寬度 | 用在 | Bootstrap 建議 |
|---|---|---|---|
| `max-w-6xl` | 1152px | 頁首、頁尾、首頁、商品列表、商品詳情 | `.container`，調整 `$container-max-widths`（或自訂 `.container-shop`） |
| `max-w-5xl` | 1024px | 購物車、結帳 | `.container` 再限制 `max-width` |
| `max-w-4xl` | 896px | 我的訂單、後台商品表單 | 同上 |
| `max-w-2xl` | 672px | 付款結果 | 同上 |
| `max-w-md` | 448px | 登入、註冊、後台登入 | 同上 |

- 要保留的是**寬窄層級**（列表頁最寬、結帳與購物車次之、付款結果較窄、登入註冊最窄），實際數值由風格決定。
- 左右內距：數值由各風格自訂（wireframe 是 16px）。Bootstrap 的限制是 `$container-padding-x` 要 **≥ `$grid-gutter-width`**，否則 `.row` 的負邊距會造成水平溢出。02 的做法：`$container-padding-x: 2.5rem`（手機左右各 20px）、`$grid-gutter-width: 2rem`。
- 前台頁面整體是**直向 flex、最小高度 100dvh**，`<main>` 會撐滿，頁尾貼底；頁尾上方要有明確間距（wireframe 64px；02 手機 64px、桌機 96px）。

### 2.2 前台共用頁首（SiteHeader）

- 高度 64px（wireframe），底部 1px 分隔線，背景與頁面底色有區隔（原稿是卡片色）。
- 內容置於最寬的容器，由左至右：

| 順序 | 元件 | 規格 | 顯示條件 |
|---|---|---|---|
| 1 | Logo | NestCraft 品牌標誌，連到 `/`（wireframe 的 28×28 方塊＋「居所家具 / logo」是佔位） | 永遠 |
| 2 | 主導覽 | 3 個連結：首頁 `/`、商品列表（或「商品一覽」）`/products`、我的訂單 `/orders` | ≥ md |
| 3 | 搜尋框 | 放大鏡 icon 加 placeholder「搜尋商品…」，會佔滿剩餘空間（wireframe 高 36px、最寬 320px） | ≥ sm |
| 4 | 登入按鈕 | 細框按鈕：人像 icon＋「登入」，連到 `/login` | 永遠；文字 ≥ sm 才顯示（風格可只用圖示，見下） |
| 5 | 購物車按鈕 | 細框按鈕：購物車 icon＋「購物車」＋數量徽章（購物車件數），連到 `/cart` | 永遠；文字 ≥ sm 才顯示（風格可只用圖示，見下） |

- **登入、購物車的文字標籤**：風格可以只用圖示，但按鈕必須有 `aria-label`（購物車要含件數），觸控範圍 ≥ 44px。02 的做法：兩者都只用圖示，`aria-label` 為「會員登入」「購物車，4 件商品」；< 576px 會員入口移到選單內。
- **導覽選中狀態**：選中項目要和其他項目有明顯區別（wireframe：加底色並改粗體）。對應關係：`/` → 首頁、`/products` → 商品列表、`/orders` → 我的訂單。wireframe 在其他頁面沒有選中項目；商品詳情頁建議也標示「商品列表」（02 的做法），購物車、結帳、付款結果、登入、註冊則不標示。選中項目加 `aria-current="page"`。
- **RWD**：原稿在 < md 時直接隱藏主導覽，**沒有漢堡選單**，< sm 也沒有搜尋入口。實作時請補上：< md 顯示漢堡按鈕，點開後用 Bootstrap Offcanvas 或 Collapse 顯示導覽連結（加上搜尋框）；小螢幕也要找得到搜尋（02：992 以下改成放大鏡按鈕展開搜尋列，< 576 會員入口移到選單內）。

### 2.3 前台共用頁尾（SiteFooter）

wireframe 的頁尾是一份「畫面索引」，方便在所有頁面之間跳轉：

- 背景與上方內容區隔（原稿為淺灰），頂部 1px 分隔線，最寬的容器。
- 標題「Wireframe 畫面索引」，下方 ≥ sm 時 **2 欄**（< sm 改成 1 欄上下排）：
  - 左欄「使用者流程」：一排小尺寸細框標籤連結（可換行），列出前台 9 頁（商品內頁連到 `/product/p-1001`）。
  - 右欄「管理者流程」：後台 5 頁。
- **實作規定**：設計稿要能 demo 跳頁，頁尾要保留一組全頁連結（可以稱為「設計稿頁面」），**只列出該風格已實作的頁面**：前台 9 頁＋設計 Guideline；有做後台才列後台。目前頁面要標示出來（`aria-current="page"`）。
- 各風格可以在它上方加一段真正的電商頁尾（品牌介紹、連結欄、客服資訊、版權）。

### 2.4 後台共用框架（AdminLayout，A2～A5，選做）

- 整頁左右兩欄、最小高度 100dvh，**沒有**前台頁首與頁尾。
- **左側欄**（≥ md 顯示，wireframe 寬 224px，右側 1px 分隔線，卡片底色）：
  1. 頂部品牌列：底部分隔線，icon（panels-top-left）＋品牌名與「後台」字樣（wireframe 寫「ADMIN 後台」）。
  2. 導覽（垂直）：「商品管理」（box icon → `/admin`）、「訂單管理」（clipboard-list icon → `/admin/orders`）。選中項目有底色並改粗體。A2、A3、A4 選「商品管理」，A5 選「訂單管理」。
  3. 底部固定：分隔線，下方「登出」（log-out icon → `/admin/login`）。
- **右側主區**：
  1. 頂列：底部分隔線，左側「管理者後台」與目前使用者（wireframe 用「管理者後台 · 使用者：admin」串成一列；實作請分開標示），右側圓形頭像。
  2. 內容區：可水平捲動（表格用）。
- **RWD**：原稿在 < md 時直接隱藏側欄，沒有替代導覽。實作時請在頂列左側加一個漢堡按鈕，點開後用 Offcanvas 顯示側欄內容。

### 2.5 共用元件

| 元件 | 規格 | 出現頁面 |
|---|---|---|
| **SectionLabel** 區塊標籤 | wireframe 用 10px 等寬大寫小字標示區塊（見 §0.1）。中文標籤 → 做成該區塊的小標題（風格自己的 h2／h3 樣式）；英文全大寫標籤 → 不顯示。**不要**照搬等寬、全大寫、加寬字距 | 幾乎每頁 |
| **ProductCard** 商品卡 | 外框或無框由風格決定，內容裁切。上：1:1 圖片（整塊連到商品頁）。下：**完整品名**（Notion 逐字，連到商品頁；太長時可限制 2 行）→ 分類（小字、次要色）→ 建議加上尺寸（W × D × H）→ 最下方一列左右分開：價格（粗體，格式 `NT$ 16,800`）／小按鈕「加入購物車」。首頁「人氣嚴選」的卡片按鈕改為「閃電結帳」（Notion）。**售完**時按鈕停用，文字「已售完」或「售完」。卡片等高，價格列貼齊底部 | 首頁、商品列表、商品詳情 |
| **CheckoutSteps** 結帳步驟條 | 3 步：wireframe 為「購物車」—「結帳付款」—「完成」（02：購物車／填寫資料與付款／完成訂單）。**已完成、目前、未到**三種狀態要看得出差別（wireframe：已完成或目前是深色外框＋實心數字圓，未到是淺色外框＋空心數字）。wireframe 是置中的膠囊橫排；位置與對齊由風格決定（02：靠左橫排，放在頁首 H1 上方，取代麵包屑）。目前步驟加 `aria-current="step"` | 購物車（1）、結帳（2）、付款結果（3） |
| **QuantityStepper** 數量選擇器 | 外框群組：「−」按鈕｜數字｜「＋」按鈕（wireframe：商品內頁按鈕 36px、購物車 32px）。按鈕要有 `aria-label`「減少數量／增加數量」；觸控目標建議 ≥ 44px | 商品詳情、購物車 |
