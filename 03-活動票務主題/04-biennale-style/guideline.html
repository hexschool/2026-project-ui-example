色彩

只有純黑、純白與中灰階。灰色各有固定用途：要當文字的灰一定達 4.5:1，當框線的灰達 3:1，其餘只能當裝飾線。對比度以「對純白」計算，括號內另註其他底色。

Bootstrap 主題色的對應

沒有彩色，所以 Bootstrap 的語意色全部收斂到黑與石墨灰。.btn-success、.alert-danger 這些 class 照樣能用，但「成功」「錯誤」看起來是什麼樣子，由下面的狀態語法決定，不由顏色決定。這是刻意的取捨：即使是錯誤，也不破例使用紅色。

Bootstrap 變數本風格說明
$primary、$dark純黑主要按鈕、選中、反白量體
$secondary、$info石墨灰次要文字
$success、$warning、$danger純黑差別由反白、斜線紋、粗框與圖示表達
$light展牆灰區塊底色
$body-bg／$body-color純白／純黑單一淺色主題，作業系統深色模式時也不變
$focus-ring-color純黑（黑底區塊改純白）3px 實線，外推 2px 白色間隙

票務專用語意：黑白狀態語法

四種手法各有一個固定的意思，再加上圖示與文字，任何狀態都至少用兩種方式表達。

  • 反白（黑底白字）＝現在、這一個

    目前頁、已選的膠囊與座位、目前步驟、已選票券、倒數警示、驗票成功

  • 斜線紋＝不能用

    已售罄、不可選座位、停用按鈕、逾時、付款失敗、驗票失敗；即將完售的進度條軌道

  • 粗框（3px）＝看這裡

    已選票種卡、購票卡、訂單明細、搜尋列、退票規則、錯誤欄位（2px）

  • 虛線＝還沒到

    尚未開賣的票種與購票卡、結帳步驟裡還沒到的步驟

票務語意示範手法
稀缺／即將完售（剩 ≤ 25%）即將完售反白標籤＋火焰圖示；進度條軌道換斜線紋、條加粗
售罄／停用早鳥全票斜線紋＋刪除線＋水泥灰框；按鈕停用寫「已售完」
選中 音樂演出反白＋勾；票種卡是粗框＋左上「已選 2 張」
倒數警示（剩 2 分鐘）01:58整列反白＋驚嘆號圖示；數字不閃爍
驗票成功（大面積） 驗票成功全黑畫面＋大勾＋文字
驗票失敗（大面積） 無效票券白底＋黑白警示斜紋框＋大 ✕＋原因

剩餘票數、售罄、即將完售一律「狀態手法（反白、斜線紋）＋文字＋進度條」三者並用；本風格沒有顏色可依靠，也就不會只靠顏色。

間距與格線

間距以 16px 為基準，Bootstrap 的 0–5 階之外擴充 6–8 階給區塊留白。

容器與格線比例

10 頁共用同一個最寬容器：1200px 以上 1140px、1400px 以上 1320px，以下滿寬（註冊頁的內容在容器裡再收窄到 960px 置中）。左右留白 24px（992px 以上 32px），欄距 32px；容器內距大於欄距，.row 的負邊距才不會造成水平捲軸。

節奏與 sticky 位移

區塊上下留白手機 64px、992px 以上 96px（.section）
頁首高度72px（$site-header-height，含 2px 黑底線）
sticky 位移104px ＝ 頁首 72＋32（$sticky-top-offset）：購票卡、篩選側欄、已選票券；購票紀錄的退票申請（≥ 1200px 寬、視窗 ≥ 1280px 高時）
結帳步驟列sticky 在 72px；訂單明細再往下 68＋24px
底部固定列72px（$mobile-bar-height），992px 以下 <body> 補同樣的下內距

圓角與陰影

全站 0 圓角：標籤、座位、輸入框、卡片、票券都是直角方塊。只有三個東西是圓的：主辦方圓形 Logo、radio、付款方式前的選鈕。分層不用陰影，改用框線粗細與反白。

元件狀態規範

以實際元件並排呈現。hover、focus、active 用 Guideline 專用的 .is-hover、.is-focus、.active 固定顯示，頁面上由真正的滑鼠與鍵盤觸發。

Do／Don’t 對照

  • Do

    還有 09:12

    倒數只更新數字，整列不閃爍、不跳動。

    Don’t

    09:12

    用閃爍動畫或放大跳動的倒數製造壓力。

  • Do

    早鳥全票 NT$ 1,200

    售罄票種保留在列表中，以刪除線呈現。

    Don’t

    （早鳥全票消失了）

    直接隱藏售罄票種，讓人以為沒賣過。

  • Do

    剩餘 8% 即將完售

    剩餘票數同時給進度條與百分比文字。

    Don’t

    只用深淺不同的色塊表示稀缺或售罄（本風格沒有紅綠，更不能只靠灰階深淺）。

  • Do

    可以退票嗎？

    退票規則與其他 FAQ 同字級，預設展開，加粗框與圖示。

    Don’t

    退票規則請見條款

    把退票規則縮成灰色小字塞在角落。

  • Do

    付款按鈕按下即 Loading 並鎖定。

    Don’t

    確認付款 × 3

    付款按鈕可連點，造成重複扣款。

  • Do

    代碼 51：額度不足

    付款失敗寫出原因與下一步（代碼 51：額度不足）。

    Don’t

    交易失敗

    錯誤只寫「交易失敗」就結束。

  • Do

    09:12 ｜ NT$ 5,974

    結帳頁永遠看得到保留倒數與應付總額。

    Don’t

    新頁面

    結帳跳出到新頁，讓人找不到回去的路。

  • Do

    狀態用反白、斜線紋、粗框、虛線，加上圖示與文字。

    Don’t

    為了「黑白」而只用灰階深淺分狀態，或破例加一個彩色。

  • Do

    把條碼當裝飾到處貼，招牌就不再是招牌。

招牌元素：巨型條碼與黑色量體

Notion 的風格定義是「俐落無襯線字體、巨型條碼與高反差幾何方塊」。大膽只花在這兩件事，其餘保持安靜。

巨型條碼

  • 用 scripts/make-barcode.mjs 產生真的 Code 128（例如 node scripts/make-barcode.mjs T-4471-01），不要手畫假條碼。
  • 只用在「票」與「品牌簽名」上：電子票券底部（編碼票號）、首頁票券小卡、全站頁尾（編碼 StageOne）、Logo 的 5 根條碼。
  • 寬度跟著容器（preserveAspectRatio="none"），高度用 --barcode-height 設定；顏色是 currentColor。
  • 條碼是裝飾：aria-hidden="true"，票號一定另外用文字寫出來。

黑色量體

  • 黑色量體留給每個區塊最重要的一件事：首頁的票券小卡與入場保障、活動細節的已選票券、結帳的應付總額、購票紀錄退款試算的預估退款；大面積黑底只用在首頁「本週最多人在看」與頁尾。
  • 量體一律直角、滿版或對齊格線，不加陰影、不加漸層。
  • 量體裡的次要文字用霧灰（8.3:1），焦點環自動換成白色（.on-ink）。
  • 首頁 Hero 反過來用白色量體壓在全黑的照片下半部，是同一個手法的反白版本。
