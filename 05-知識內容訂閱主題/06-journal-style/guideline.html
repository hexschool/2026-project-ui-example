00概覽

這一節的原則

一本隨身手帳：點格紙、便利貼、紙膠帶、拍立得和螢光筆是外皮，資料區一律端正。字是藍黑墨水，珊瑚與抹茶只當填色，讀起來沒有負擔。

風格定義（Notion）

手帳筆記插畫｜淺色系＋暖色調（淺奶油、柔和珊瑚橘、抹茶綠）

編輯器工具列帶有手繪風標籤，訂閱方案按鈕圓潤可愛，營造輕負擔氛圍。

品牌記號：手繪小筆記本

現場筆記 FieldNotes

奶油色手帳、珊瑚書籤、抹茶橫線、藍黑活頁圈。頁首、頁尾的品牌記號和 images/favicon.svg 是同一個圖形（favicon 多一塊桌面色圓角底），顏色都從 class 或 token 來。

設計原則

  1. 實物外皮，資料端正。紙張、便利貼、紙膠帶、拍立得、圓形貼紙、票券、對話泡泡、橫線紙都用 CSS 或 inline SVG 畫。只有裝飾性的容器可以傾斜；表單、表格、長文、文章卡、方案卡、按鈕不傾斜，也不加塗鴉，每頁塗鴉 3 到 5 個。
  2. 藍黑墨水寫字。標題與介面字是 $pen，長文是 $pen-body。珊瑚與抹茶只當填色，需要珊瑚色的字用 $coral-ink，需要綠色的字用 $success。
  3. 螢光筆只畫一半。H1 只在最重要的那半句畫珊瑚螢光筆；導覽目前頁、目錄目前項、本頁索引的目前節用同一支筆。標題不加粗，Huninn 只有 400 一個字重。
  4. 輕負擔但不隱瞞。大量留白、便利貼、柔和陰影，沒有警告式的紅色大塊；取消、退費、到期日照樣寫在看得到的地方。
  5. hover 不改尺寸。hover 只換底色、底線、框線，或讓紙膠帶變深；不位移、不旋轉、不展開隱藏的內容，資訊常駐顯示。

11RWD 斷點

這一節的原則

沿用 Bootstrap 斷點，每個寬度都沒有水平捲軸；橫向捲動只發生在明確的容器裡（比較矩陣、資料表、損益表、分頁籤、作者牆、本頁索引）。手機上手帳的外皮照樣在，資料區照樣端正。
