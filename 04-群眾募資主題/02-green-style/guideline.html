00

概念與招牌

概念是「苗圃」：每個提案是一株正在長的苗，平台要做的是把「長到哪裡了」清楚寫在標示牌上。畫面是明亮的再生紙底和大量留白，綠色只用來說「正在長」與「已經長到」；語氣溫和、不催促，不用促銷紅、不用倒數閃爍。Notion 對這套風格的要求有三點，各自對應一個招牌元素：

1溫和的圓角進度條＝生長條

粗的全圓角進度條。達成的部分是森林墨綠；超過目標之後「新長出來」的部分換成初生綠，兩段之間一道刻痕就是目標 100%。看一眼就知道「達標了，而且多長出了多少」。

一只走十年的台南帆布包：247%，刻痕在 500,000 ÷ 1,235,600 ≈ 40.5% 的位置

2留白舒適的贊助方案卡

方案卡是全站留白最多的元件：28px 圓角、桌機 36px／40px 內距、清單用葉片圖示。一張卡只回答一件事「付多少、拿到什麼、什麼時候拿到」，選取時用 2px 森林墨綠框＋淡初生綠底＋實心勾。

3易於搜尋引擎索引的圖文區

專案故事是 SEO 的主戰場：一頁一個 h1、故事 5 個 h2、圖片用 figure＋figcaption 與完整 alt、規格用表格、數字用 data 與 time。搜尋引擎、螢幕閱讀器與人讀到的是同一份結構。

預縮處理

h3 只用在 h2 底下的細分，和 h2 差 6px，和內文差 3px 並加粗，三個層級一眼分得出來。專案頁的故事照 Notion 只有 5 個 h2，不另外加 h3。

03

語意化與 SEO

Notion 對這套風格的要求是「專案圖文區易於 SEO 爬蟲索引」。做法不是加關鍵字，而是讓 HTML 本身就是一份清楚的文件：標題有層級、內容沒有藏在分頁籤裡、數字與日期機器讀得懂、圖片說得出畫面。

元素用在哪裡、為什麼
<h1>–<h3>一頁一個 h1；h2 是區塊、h3 是區塊內的項目，不跳級、不用 div 加大字代替
<article>可以單獨被引用的內容：專案故事、專案卡、每則留言
<figure>＋<figcaption>故事配圖；alt 描述實際畫面，圖說用 alt 的內容，不另寫文案
<dl>＋<data value>募資儀表板、數據卡、提案者紀錄：標籤和數字成對，value 是機器讀的純數字
<time datetime>募資期間、里程碑月份、更新日期、留言時間
<table>＋<th scope>規格與尺寸、圖表的表格檢視；不做成圖片
<nav aria-label>主要導覽、麵包屑、頁內導覽、本頁目錄，各自有名字
麵包屑微資料itemscope itemtype="…/BreadcrumbList"：搜尋結果可以顯示階層，不需要 script
<img>都有 alt、width、height（版面不跳動）；首屏圖 fetchpriority="high"，其他 loading="lazy"
<title>、description「頁面名稱｜島造 ISLANDMAKE 在地製造提案平台」；專案細節的 description 用 Notion 一句話副標

寫法：儀表板的數字

<dl class="pd-dash-amount">
  <dt>目前募得</dt>
  <dd><data class="figure-num" value="1235600">NT$&nbsp;1,235,600</data></dd>
</dl>
<dl class="pd-dash-period">
  <dt>募資期間</dt>
  <dd><time datetime="2026-09-15">2026/09/15</time> – <time datetime="2026-10-15T23:59">2026/10/15 23:59</time></dd>

  • 頁內導覽用錨點連結，不用會隱藏內容的分頁籤：風險揭露不能被收起來，故事也要讓搜尋引擎一次讀到。
  • 進度條只是視覺輔助（aria-hidden="true"），數字一定以文字出現在旁邊。
  • 上線時再補 canonical 網址、Open Graph 分享圖與 sitemap；設計稿沒有正式網域，所以先不寫。

05

圓角陰影

溫和來自圓角，不來自陰影。卡片一律不加陰影，用白卡＋1px 細線或色塊分層；陰影只給「浮起來、跟著畫面走」的面。

  • 8px $border-radius-sm
    縮圖、下拉選單項目

  • 12px $border-radius
    輸入框、提示框、表格外框

  • 20px $border-radius-lg
    照片、數據卡、圖表卡

  • 28px $border-radius-xl
    方案卡、專案卡、儀表板

  • 40px $border-radius-xxl
    提案者轉換帶

  • 全圓 $border-radius-pill
    按鈕、徽章、生長條、篩選標籤

sm照片上的標籤、目錄列
預設sticky 儀表板、小計卡、下拉選單、卡片 hover
lg對話框；手機底部行動列用向上的陰影

陰影的顏色是深林 #1C3D2C 的透明版，不用純黑，在再生紙底上不會髒。

數據圖表

圖表用 inline SVG（折線、面積）或 HTML／CSS（橫條），不引入圖表套件。所有顏色都是 CSS 變數，加上 .chart-dark 就換成深色底的一組——不是自動反轉，而是另外挑過的顏色。

  • 單一數列一色：淺色底用森林墨綠、深色底用初生綠；方案分佈 5 條同一色，「已額滿」「即將額滿」用文字標註。
  • 一張圖一個 y 軸：累積金額與目標同單位才放在一起；贊助人數另畫，不做雙軸。
  • 格線 1px 實線退居背景；只有目標線是虛線（原木褐），並直接標註「目標 NT$ 500,000」。
  • 只標端點與極值：開賣首日、媒體報導、今日；單一數列不放圖例。
  • 每張圖都有表格檢視（「切換表格檢視」展開 Collapse）；SVG 有 role="img" 與描述重點的 aria-label。
  • 篩選器放在所有圖表上方，不放進單張圖卡；手機上 SVG 最小寬 600px，只在圖卡內橫向捲動，座標文字 ≥ 10px。
  • 提示框格式：「09/24（四）」換行「當日募資 NT$ 72,000」；命中範圍 ≥ 24px。

RWD 斷點

斷點沿用 Bootstrap 5。驗收寬度 390／768／992／1200／1440／1920：都不能有頁面層級的水平捲軸；分頁籤列、縮圖列、表格、手機上的圖表只在自己的容器內橫向捲動。

斷點寬度專案卡這個斷點的關鍵變化
xs< 5761 欄專案細節有底部固定行動列；篩選是全螢幕浮層；縮圖列橫向捲動；統計列 2 × 2
sm≥ 5761 欄統計列一列 4 格；贊助紀錄卡變成 3：6：3
md≥ 7682 欄專案列左圖右文 5：7；方案卡內部 8：4、選取圓移到左側
lg≥ 9923 欄側欄、sticky 儀表板與目錄啟用；Hero 6：6、細節 7：5、個人頁 3：9；結帳、贊助成功、贊助紀錄詳情 7：5；底部行動列消失；區塊留白 64 → 96px；容器留白 20 → 32px

無障礙底線

  • 觸控目標 ≥ 44 × 44px：按鈕、篩選標籤、麵包屑連結、頁尾連結、分頁籤都有最小高度。

  • 焦點樣式：森林墨綠 2px 實線＋2px 間隙；深色底換成初生綠。
