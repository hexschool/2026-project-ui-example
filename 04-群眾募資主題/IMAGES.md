# 島造 ISLANDMAKE：共用圖片清單

六套風格（01-hardware-lab-style、02-green-style、03-bold-style、04-indie-press-style、05-business-style、06-toy-factory-style）用**同一份清單、同一組檔名**，各自依風格重新生成。
畫面主體（拍什麼、構圖、必要細節）六套一致；光線、色調、背景材質、景深、後製等「風格」由各套的 `STYLE` 字串決定。
所以下面的描述刻意**風格中立**：不寫顏色調性與氣氛，只寫內容。

共 **23 張**，全部放在各風格的 `images/`，檔名英文小寫加連字號。favicon 由各風格自己畫 SVG，不在此清單內。

## 共同規則

- **生成比例只有三種**（Codex CLI 實測：prompt 寫 3:2 輸出 1536×1024、寫 square 輸出 1024×1024、寫 2:3 輸出 1024×1536），存檔時依 01 電商的慣例縮成：
  - 3:2 → **1600×1066** JPEG（品質 80）
  - 1:1 → **1200×1200** JPEG（品質 78）
  - 2:3 → **1066×1600** JPEG（品質 80）
- **顯示比例**由 CSS 決定（`aspect-ratio` ＋ `object-fit: cover`），所以生成時主體要放在畫面中央的安全區，四周留邊，裁成 16:9、4:3、4:5 都不會切到主體。
- **一律不要**：文字、招牌字、商標、浮水印、品牌標誌、可辨識的真實人物。AI 畫中文字常常是亂碼，畫面裡有標籤、書封、看板時，要求「blank labels / no readable text」。
- 人物只拍**手部、背影、側面或遠景**；需要臉的只有提案者頭像（`proposer-avatar`），用虛構人物。
- 場景設定在**台灣**（台南、新竹、高雄、南投、嘉義、台中、台北），但不要靠文字招牌表現地點。
- 圖片內容要和 `CONTENT.md` 的文字一致，例如帆布包的顏色只有「原胚、墨綠、炭黑」三種，咖啡渣杯是「隨行杯」不是馬克杯。
- `alt` 文字寫在下表最右欄，六套共用（專案故事的圖片 Notion 規定一律要有 alt）。只當裝飾的圖用 `alt=""`。
- 生圖腳本沿用 `01-電商主題/01-luxury-style/scripts/generate-images.mjs` 的寫法：`STYLE`＋各張 prompt；prompt 用英文寫，把下表「畫面主體」翻成英文即可。
