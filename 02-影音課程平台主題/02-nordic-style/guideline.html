概覽

像在北歐大窗邊的白色書桌上課：雪白底、冰河藍點綴，所有側欄都是一張張輕卡片，白天看一整個下午也不累。

風格
設計稿 02｜北歐明亮課室
色系搭配
淺色系＋冷色系（雪白、冰河藍、低飽和灰）
UI 視覺特點
章節目錄與隨堂筆記側欄採用輕量卡片，留白寬裕，適合長時間白天學習
招牌語彙
窗（圓角主圖與播放器卡框）、輕卡片（髮絲線＋很淡的雙層陰影）、一疊分開的輕卡片側欄、橫線筆記紙、頁面上方的窗光

設計原則

  • 文字不壓在圖上照片放在圓角的「窗」或白卡裡，標題與說明永遠在雪白底上，對比穩定。

  • 層級靠留白與高度不用分隔線、色帶與裝飾線；白卡浮在雪白底上，髮絲線與淡陰影兩個都要有。

  • 冰河藍只給動作主要按鈕、連結、焦點環、進度、選中狀態才用冰河藍；一組動作只有一顆實心按鈕。

  • 寬裕的白天節奏區塊之間 120px、卡片之間 24px、內文 17／1.9；資訊常駐顯示，hover 不撐開、不展開。

色彩

雪白是頁面底、白是卡片，冰河藍是唯一的動作色，播放器維持深色。對比度依 WCAG 2.x 公式計算；文字至少 4.5:1，圖示與框線至少 3:1。

用色比例示意：雪白 48%（頁面底）、白 26%（卡片）、霜藍 12%、冰 4%、墨 6%（文字）、冰河藍 3%（動作）、夜色 1%（播放器）。

招牌元素

大膽只花在兩處：主圖像一扇窗，以及學習頁一疊分開的輕卡片側欄。其他地方極度克制。

窗 .window

  • 24px 圓角、overflow: hidden，內縮 8px 一條淡冰河藍 1px 細線，像窗框。
  • 首頁首屏的主圖就是一扇窗（≥ 992px 高度扣掉上 24、下 48px，正在播放卡跨出窗緣 24px）。
  • 課程詳情、學習頁的播放器卡框 .player-frame 沿用同一個語彙：白卡裡放 10px 圓角的深色播放器，卡框內緣一條細線。
  • 細線只是裝飾（2.71:1），不承擔辨識；文字不壓在窗上。

輕卡片 .lite-card

白底＋1px 髮絲線＋很淡的雙層陰影，內距 24px（手機 20px）、16px 圓角。四種變體：

基本內距 24，一般內容卡、表單卡、講師卡

.is-snug內距 12，圖片「裱」在卡片裡

.is-frost霜藍底、無陰影：總金額、退費說明這類次要面板

.is-link（hover）陰影加深一階、框線換淡冰河藍，不位移、不放大

輕卡片側欄（學習頁）

側欄不是一塊面板，而是一疊分開的 .lite-card：進度卡在上，每一章一張可收合的章節卡，卡與卡之間 10～12px；目前單元＝冰底＋左側 3px 冰河藍條。實際元件見下方「元件狀態規範」的單元列。

橫線筆記紙 .paper-lines

學習頁的單元重點與課程問答輸入框。很淡的冰河藍橫線，線距等於行高（手機 16px × 1.85、≥ 992px 17px × 1.9，字級與線距在同一個斷點一起換），所以字一定落在線上。只放 CONTENT.md 的原文，不另加「隨堂筆記」字樣。

單元重點（白卡）

本段重點是拇指下壓時維持約 45 度，底部厚度保留 0.8cm。壓太快會讓底部變薄，入窯容易裂。

窗光

頁面最上方 960px 是一層很淡的 linear-gradient(160deg, #FFFFFF, $snow 45%)，在頁首與首屏後面，1920 寬時滿版。內容仍留在 1200px 版心裡。

元件狀態規範

下面都是頁面實際在用的元件與類別；hover、focus 用只在本頁出現的 .gl-hover、.gl-focus 固定顯示。所有 hover 只換顏色、底色、框色與陰影，不改尺寸、不推擠版面。

按鈕

10px 圓角（不是膠囊），高 48px（小按鈕 44px）。主要＝冰河藍實心，一組動作只放一顆；次要＝白底冰河藍框（免費試看、加入願望清單）；低強調＝白底灰框（清除篩選、下載、查看全部評價）；文字連結＝冰河藍底線。停用不疊透明度，改成冰底＋石板灰字，看得出「存在但現在不能按」。

動態與 hover

白天的書桌是安靜的：只有三種動態，prefers-reduced-motion: reduce 時全部關閉（_base.scss）。

  • 顏色、框線、陰影的轉場

    .2s ease。按鈕、連結、膠囊、單元列、可點卡片的 hover 與 focus。

  • 進度條長出來一次

    .6s，載入時內層用 scaleX 從 0 長到目前值，外框尺寸不變；只發生一次。

  • Bootstrap 原本的轉場

    Offcanvas（課程列表篩選、學習頁章節抽屜）、Modal、Collapse、Toast、Tab 的淡入與展開，以及錨點連結的平滑捲動（Bootstrap reboot 的 scroll-behavior: smooth）。

hover 與 focus 的規則

  • 只換顏色、底線、框色、底色或加深一階陰影；不改尺寸、不位移、不放大、不推擠版面。
  • 資訊常駐顯示：工藝情境卡的課程數與完課時間、課程卡的價格與免費試看、播放器控制列，都不靠 hover 才出現。
  • 每個可互動元件都有看得見的 :focus-visible（2px 白色間隙＋2px 冰河藍，播放器上換成 $player-icon），focus 的樣子和 hover 不同。
  • 選中狀態不換字重（分頁籤、分段控制），避免寬度變動。
  • 同一頁內的錨點連結（本頁目錄、課程詳情的星等）平滑捲動到位，scroll-padding-top 讓開頁首；prefers-reduced-motion 時直接跳到位。
