概覽

熄燈後的放映廳：每一頁的 95% 是深空黑，只有「你正在看的東西」會亮。銀幕（播放器）是純黑，控制列平常是低調的銀灰，滑鼠移上去或用鍵盤聚焦時，才從底部浮起一層微光冷藍。

風格定位
極致暗黑劇院
色系搭配
深色系 ＋ 冷色系（深空黑、微光冷藍、純白）
UI 視覺特點
95% 暗底專注介面，播放控制器僅在滑鼠懸停時發出柔光，降低視覺干擾。
品牌
專為「想養成第二專長、但一直沒開始」的上班族打造的工藝影音學院，匯集各領域台灣在地職人開設的線上課程。

以上文字引用自課程規格文件（Notion）。

設計原則

只有看著的地方會亮
靜止的畫面只有黑與灰。冷藍只出現在被看著的東西上：hover、鍵盤焦點、播放中、目前單元、主要按鈕。課程卡與工藝卡平常略暗（亮度 78%），滑鼠移上去或 Tab 到時「亮燈」。
銀幕最黑
播放器一律純黑 #000，比頁面的深空黑再暗一階，眼睛自然落在影片上。學習頁的放映區比一般版心寬（最大 1680px）。
純白是片頭字卡
純白留給標題與關鍵數字（價格、片長、時間碼）。大標用 Noto Sans TC 300 細字＋寬字距，數字用 Jost（Futura 系的電影片頭字）。內文用霧白，說明用銀幕灰。
看得見才算低調
「降低視覺干擾」不等於隱藏：控制列靜止時仍有 10:1 的對比，鍵盤與觸控使用者一定看得到；文字對比至少 4.5:1，框線與焦點至少 3:1。

頁面

依學生流程：瀏覽課程 → 註冊登入 → 購買課程 → 觀看影片。

  • 首頁index.html
  • 課程列表courses.html
  • 課程詳情（含試看）course.html
  • 課程播放／學習頁learn.html

檔案與共用區塊

  • 每一頁都是一份完整的 HTML，用 <a href="courses.html"> 這類相對連結換頁；課程詳情只有一頁 course.html（從零開始的手捏陶），所有課程卡都連到這裡。
  • 頁首、頁尾、登入對話框在每一頁都完整寫一份。要改時先改 templates/page.html，再同步到每一頁，最後執行 npm run check。
  • 樣式寫在 scss/，改完執行 npm run css；互動只用 Bootstrap 的 data-bs-* 與 js/main.js 的六個小功能。
  • 本風格的共用類別：亮燈 .lit（_base.scss）、柔光控制列 .player（components/_player.scss）、單元列 .unit（components/_curriculum.scss）、標籤 .chip（components/_chips.scss）。

使用規則

  • 亮起的觸發：.player:hover 與 .player:focus-within（鍵盤 Tab 進控制列就亮）。
  • 觸控裝置沒有 hover：@media (hover: none) 直接維持亮起狀態，手機上一定看得到完整控制列。
  • 永遠不要把控制列設成 opacity: 0 或 display: none；「降低干擾」是降低亮度，不是隱藏。
  • 亮起與熄滅的轉場 .35s（$glow-transition）；prefers-reduced-motion: reduce 時沒有轉場，直接切換。
  • 柔光只用 token：$glow-rise（控制列底部）、$glow-halo-sm（進度條、播放頭）、$glow-halo-lg（大播放鈕、主要按鈕 hover）。
  • 同一套語言延伸到卡片：.lit 讓課程卡、工藝情境卡平常略暗，hover／focus 時亮燈並浮出 $glow-halo。

色彩

深空黑為底、純白寫字、微光冷藍只在被看著的時候出現。三層深色只差一點明度，靠髮絲線分出邊界。

對比度依 WCAG 公式計算，未特別註明時是對頁面底色「深空黑」的比值。文字需達 4.5:1（AA），邊框、焦點、圖示等非文字元素需達 3:1。

面

由深到淺三層＋播放器的純黑，都帶一點藍，不用中性的 #111。浮起的面靠髮絲線畫出邊界，不靠陰影。

課程名稱的換行

課程名稱、短標題加 .text-phrase（word-break: keep-all），在「｜」之後用 <wbr> 標出斷點；數字與單位之間用 &nbsp;（4&nbsp;小時），不會被拆成兩行。
