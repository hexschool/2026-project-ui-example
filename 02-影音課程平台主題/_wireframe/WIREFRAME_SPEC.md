### 0.2 文案規則

1. **逐字**：`CONTENT.md` §1～§8 的文字照抄，包含全形標點（｜／‧、全形空白、＆）、數字格式（`NT$ 2,480`、`4 小時 20 分`、`08:42`）與 en dash（`NT$ 2,000–3,000`）。
2. **拆開排、不改字**：Notion 用 ` ｜ ` 把多項資訊寫在同一行時（資訊標籤列、經歷、購買包含），拆成各自的元素，每項的字照抄（`CONTENT.md` §0）。課程名稱裡的「｜」是名稱的一部分，要保留。
3. **icon 提示**：Notion 文案裡的 ▶ ♡ ✓ ← → ○ ★ 🔓 🎉 與首頁 4 個 emoji 可以換成 Bootstrap Icons；換掉時，旁邊的文字照抄。
4. **Notion 沒寫的**：數字（星等、評價數、單元名稱、進度）與介面文字（按鈕、標籤、aria-label、頁尾）統一用 `CONTENT.md` §9，不要每套自己編。
5. **wireframe 自己的文字不要用**，清單見 §5。

### 0.3 動態功能的靜態呈現（設計稿狀態示意）

設計稿沒有後端、沒有真的影片。下面這些功能用「靜態畫面＋設計稿狀態示意」呈現。**設計稿狀態示意**沿用 01 的做法：在該頁 `<main>` 最後放一個 `<section class="demo-state">`，最上方一個小標籤「設計稿狀態示意」，用虛線或底色和正式內容分開，裡面每個狀態一個小標題（「篩選沒有結果時」）＋畫面。

| 功能 | 設計稿怎麼做 | 位置 |
|---|---|---|
| 影片播放 | `<img>` 當畫面，疊上 HTML／CSS 畫的播放鈕與控制列；不放 `<video>`，按了不會播放 | 首頁小卡、課程詳情、學習頁 |
| 播放速度、字幕 | Bootstrap Dropdown（`data-bs-toggle`，不用自己寫 JS），選單裡的選項可以點但不會改變畫面 | 播放器控制列 |
| 進度記憶、續看 | 學習頁進度條固定在 07:18／11:24，標出「已觀看位置」；續看 Toast 預設就顯示（`.toast.show`），可以關掉 | 學習頁 |
| 免費試看 | 課程卡「▶ 免費試看」連到 `course.html#trial`；課程章節的試看單元連到 `#trial` | 首頁、課程列表、課程詳情 |
| 未登入點擊購買 | 「立即購買，開始上課」開啟登入對話框，標題下方顯示 Notion 文案；對話框送出到 `checkout.html`（**2026-11 改**：原本直接到 `learn.html`，視為登入並購買成功；現在接著走購買課程、付款結果兩頁） | 課程詳情（實際可點）、Guideline |

| 已購買者的章節勾選 | 另外畫一份「已購買時」的章節清單與購買卡 | 課程詳情狀態示意 |

| 標記完成、完成一章、全課完成 | 「✓ 標記完成並繼續」連到同一頁；鼓勵文案與全課完成畫面放在狀態示意 | 學習頁 |
| 影片載入失敗 | 播放器大小的錯誤畫面 | 學習頁狀態示意、Guideline |
| 我的課程為空 | 靜態畫面 | 學習頁、我的課程狀態示意、Guideline |

### 0.5 2026-11 補的 5 頁：內容一致，排版各自發揮

使用者 2026-11-17 看了 05 知識訂閱主題的補頁，覺得兩套風格「排版太像了，可以讓他們有些落差」。所以 §3.05～3.09 這 5 頁的規定分成兩層：

| 6 套一致（照本文件與 `CONTENT.md` §9.9～§9.14） | 各風格自己決定（照自己既有 5 頁的排版語言） |
|---|---|
| 每頁有哪些區塊；區塊裡的元件、欄位與按鈕 | 桌機欄數；區塊左右排或上下排 |
| 文案、示意資料（編號、日期、金額、進度） | 卡片、列表或表格的呈現方式 |
| 狀態與設計稿狀態示意、連結與送出目的地 | 側欄或摘要放哪裡、要不要 sticky |
| 表單的 `type`、`autocomplete`、`name` 規則；頁首目前頁；`<title>` 與 description | 標題區的構圖、留白、裝飾 |

- §3.05～3.09 寫的「容器與欄數」都是**建議**。做新頁之前，先看自己這套的 `courses.html`、`course.html`、`learn.html` 怎麼排，新頁要看起來像「這套風格」的一部分，而不是 6 套共用同一個版型、只換顏色。
- 不要為了不同而犧牲可讀性或 RWD；必要元素（表單欄位、摘要、金額、狀態、主要按鈕）一個都不能少。
- **hover／focus 不能改變尺寸或版面**（使用者 2026-11-17 的決定，新頁一律照做）：hover 與 focus 只用不影響尺寸的變化，例如顏色、底線、邊框色、背景色、克制的陰影、不推擠版面的圖示小位移。不要 hover 才展開隱藏內容（`max-height: 0` 變成有高度、`grid-template-rows: 0fr` 變成 `1fr`、`display: none` 變成顯示），不要讓卡片變高、變寬或推擠周圍元素；要給的資訊（進度、上次看到的單元、訂單備註等）直接常駐顯示。既有頁原本 hover 才浮現的 CraftCard 課程數與完課時間（§2.5、§3.01），已在全部補完後統一改成常駐顯示（2026-11-17，當時的 01、04、05 都改；2026-11-18 新增的 02、03、06 一開始就常駐顯示）。

## 2. 全域規格

### 2.1 斷點與容器

原稿是 Tailwind，斷點與 Bootstrap 5 略有不同。**以 Bootstrap 斷點為準**：

| 原稿（Tailwind） | 寬度 | 對應 Bootstrap | 寬度 |
|---|---|---|---|
| `sm:` | ≥ 640px | `sm` | ≥ 576px |
| `md:` | ≥ 768px | `md` | ≥ 768px |
| `lg:` | ≥ 1024px | `lg` | ≥ 992px |
| — | — | `xl` | ≥ 1200px |
| — | — | `xxl` | ≥ 1400px |

- 檢核寬度：**1440／1200／992／768／390**（含 Bootstrap md／lg／xl 邊界與手機），都不可以出現水平捲軸。2026-11 補的 5 頁另外加檢 **1920**。
- **容器**：wireframe 全站同一種寬度：`max-w-7xl`（1280px），左右內距 20px（< 1024）／32px（≥ 1024），1440 寬時內容寬 1216px。實作用 Bootstrap `.container`（預設 xxl 1320px），或調整 `$container-max-widths` 讓 xl／xxl 接近 1280；**所有頁面用同一種容器**，學習頁也一樣（極致暗黑劇院若想讓播放區更寬，可以在學習頁用 `.container-fluid` 加最大寬度，但頁首、頁尾仍用 `.container`）。
- `$container-padding-x` 要 **≥ `$grid-gutter-width`**，否則 `.row` 的負邊距會造成水平溢出（01 的做法：`$container-padding-x: 2.5rem`、`$grid-gutter-width: 2rem`）。
- 頁面整體是**直向 flex、最小高度 100dvh**（`d-flex flex-column min-vh-100`），`<main>` 撐滿，頁尾貼底；頁尾上方要有明確間距。
- 區塊上下留白：wireframe 為 56～64px（`py-14`／`py-16`），內頁 `<main>` 上方 32～40px。數值由風格決定，但同類區塊要一致。
